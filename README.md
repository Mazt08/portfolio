# Portfolio — Rex Mazt08

Personal portfolio site built with React + Vite + Tailwind CSS. Showcases projects, blog posts, and a contact section.

## Overview

- **Tech**: React, TypeScript, Vite, Tailwind CSS
- **Features**: Dark/light theme, responsive layout, project cards, blog posts, contact form
- **Author**: BSIT Student / Prompt Engineer & AI-Assisted Developer

## Live

Hosted at: https://github.com/Mazt08/portfolio

## Usage

```bash
npm install
npm run dev
```

## Structure

- `src/` — React components, pages, hooks, data
- `index.html` — Entry HTML with meta tags
- `vite.config.ts` — Build config
